# MNIST-v1 Preservation Audit

**Branch:** `agent/mnist-v1-preservation`

**Status:** In progress — archived-artifact rerun complete; clean source rebuild pending.

## Purpose

This audit freezes the first MNIST application as a reproducible FPGA-v1 baseline
before the project renames the application and begins the deeper Loihi-like
FPGA-v2 architecture.

The preservation standard has two independent requirements:

1. **Archived-artifact reproducibility** — previously accepted hardware binaries
   can still be programmed and reproduce the expected physical result.
2. **Source rebuild reproducibility** — a clean source checkout and pinned
   toolchain can regenerate a valid hardware image that reproduces the same
   architectural behavior.

The audit is not complete until both requirements pass.

## Remaining source-rebuild gate

The next audit step is a deliberate clean regeneration of the accepted hardware
from source.

The rebuild must begin only after the original binaries have been copied and
hashed, because the current build scripts remove their target build directories.

The required source chain is:

```text
Neuromorphic Digital Twin/hls/core_v1/run_m11_4.sh
        ↓
packaged neuron_step_v1 HLS IP
        ↓
applications/mnist/fpga/run_mnist_09_bitstream.sh
applications/mnist/fpga/run_mnist_10_bitstream.sh
        ↓
regenerated MNIST-09 and MNIST-10 hardware images
        ↓
physical rerun against frozen mnist-v1
```

A regenerated bitstream is **not required to have the same SHA-256** as the
historical bitstream. Vivado implementation artifacts are not assumed to be
bit-for-bit reproducible. The source-rebuild gate instead requires:

- the pinned Vitis/Vivado version is accepted by the scripts;
- HLS packaging succeeds;
- Vivado synthesis/implementation/routing succeeds;
- the repository resource/timing guards pass;
- required `.bit` and `.ltx` artifacts are produced;
- both MNIST profiles physically classify the selected preservation anchor
  correctly; and
- MNIST-10 physical cycle counts still equal the independently predicted cycle
  vectors.
