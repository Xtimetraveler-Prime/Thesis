`loihi_core_v2_tick` is a **per-logical-core, per-logical-timestep** kernel. It clears 64-bit local input accumulators, expands axon IDs through shared synapse rows, accumulates signed weights, iterates *all compartments*, updates state in place, writes a 256-bit trace per compartment, and emits routing packets for tick `t+1`. The HLS engine has **1024 compartments**, **4096 input axons**, **4096 events**, **32768 synapse entries**, and **4096 route slots** as compiled maximums; these are *old per-core memory capacities*, not proposed v1 requirements. Old `ap_uint<64>` state packs 24-bit current, 24-bit voltage and 16-bit refractory. Configuration packs two 13-bit decays, 24-bit threshold/bias/reset and 16-bit refractory duration. Separately, output events use 32-bit physical event words (12-bit axon ID), and packets are 64-bit destinations/time.

**Exact old neuron order:** current_work = saturate24(old_current + incoming64); current_after = saturate24(current_work - sign_ceil_abs(current_work * current_decay / 4096)); voltage_decay_base = saturate24(old_voltage - sign_ceil_abs(old_voltage * voltage_decay / 4096)); if refractory > 0, suppress spike and write reset voltage; otherwise voltage_work = saturate24(voltage_decay_base + current_work + bias), fire **only when voltage_work > threshold**, reset on spike and initialize refractory; otherwise preserve voltage_work. `current_after` is stored even when it is not used to compute this tick's voltage. The HLS ingress rejects nonzero encoded synaptic delay (status `STATUS_UNSUPPORTED_DELAY`); v3 routing packets target `t+1`. **This is not the M02 rev1 equation.**

**Actual interfaces/control:** `#pragma HLS INTERFACE ap_ctrl_hs port=return`, nine explicit `ap_memory ram_1p` array ports (config, state, axon, synapse, route descriptor, route, ingress events, trace, packet) and `ap_vld` outputs for counts/status. The HLS function itself has **no AXI4 master or AXI4-Stream** interface and does not hard-code 27 logical cores. P03/P05 wrappers attach XPM dual-port memory, host arbitration, context selection and per-tick barriers; P08 dispatches a single paged context and expects host save/load, routing and global barrier control. AXI/DDR paging occurs in separately integrated fabric/controller logic—not through an HLS neuron-update AXI burst port. Avoid equating an HLS invocation with a DDR transaction or extrapolating a stand-alone initiation interval from whole-core route/BRAM timing.

**Historical evidence, NOT M04 measurements:** v3 P03 implementation notes report the first routable compute shell WNS +1.468 ns at a **100 MHz shell target**; a later host-accessible 48-BRAM shell routed at +0.953 ns but **failed the memory-retention gate**. Separate P02/P03 accepted physical notes describe DDR paging, A53 service, trace correctness, and resource/route checks for specific past designs. None establishes v1 neuron-update II, stall rate, area, routed timing, complete-service latency, energy, or a matched DDR/on-chip speedup. Original HLS resource log values were **not reproduced or remeasured** for M04.

## M04.2: behavioral and architectural difference matrix

| Topic | Historical v3 HLS | Accepted M02 revision 1 | M04 consequence |
| --- | --- | --- | --- |
| Unit of work | Whole logical core for one tick, scans each compartment | Per logical neuron/tick; dense oracle evaluates each; exact M03 skip only under proved condition | Extract a **stateless** one-neuron update; M05 decides worklist/scheduling |
| State | Signed 24-bit voltage AND signed 24-bit synaptic current, 16-bit refractory | One signed W-bit membrane (`4..32`, default 16); no other neural state | Old state packing and post-update sequence **cannot** be reused |
| Leak | Two decay rates, `x - ceil_away(x*decay/4096)`; saturates | `trunc_toward_zero(prev_voltage * num / den)` directly | Replace leak function; signed negative edge cases differ |
| Input and clipping | Ingress 64-bit accumulator; separately saturates current before voltage and may retain current | Signed external + scheduled deliveries summed **before one final W-bit clamp** | Reuse only the **concept** of widened accumulate, not current_work semantics |
| Threshold | Strict `>` | Inclusive `>=` | Mandatory change |
| Bias/reset | Per compartment 24-bit bias, reset; reset after spike | Per neuron W-bit bias, reset; same tick reset in trace | Parametric new width; reset handling concept survives |
| Refractory | Present, suppresses firing and forces reset voltage | Absent | Delete entirely |
| Delay | Ingress HLS rejects encoded nonzero synaptic delay; v3 emitted routes tagged `t+1` | Any integer edge delay `>=1`, self/recurrent allowed | External scheduler/time bucket; do not reuse old delay gate |
| Event meaning | Input **axon IDs** expanded through table and template row | External event is signed `(tick, neuron, current)`, plus delayed synaptic arrivals | Fully different ingress semantics; v1 neural engine consumes **aggregate current** |
| Event ordering | Kernel accumulates ingress events, scans all compartments, generates routes | All current same tick coalesced, positive delays preclude same-tick feedback; sorted (tick,id) traces | Scheduler owns order, barriers, future event delivery |
| Layout/IDs | Per-core 1024-compartment banks, axon/route words and packet destination logical core | Flat network IDs; placement/cache block independent of physical engine | Decouple **logical neuron, state block, physical pipeline** |
| HLS ports | `ap_ctrl_hs`, nine `ap_memory` banks, `ap_vld` scalar outputs | No existing hardware port contract | v1 request/response provisional; real streaming/AXI mapping deferred |
| AXI, DDR and service | Separate P03/P05/P08 fabric, old core dispatch per step/slot and historical A53 path | M01/M03 model only; no v1 physical DDR/AXI path | Avoid wrapping the whole-core shell by default |
| Verification | P03/P04 v2-generated HLS testbenches and older physical traces | Two independent M02 modules + hard-coded neural fixtures + M03 exact-skip | New **M02** functional diff; v3 traces remain only historical context |

## Proposed *minimal* v1 evaluation boundary (M04.2)

`M04Request`: `neuron_id:u32`, `neuron_count:u32`, `tick:u64` (metadata), `previous_voltage:i32`, `aggregated_current:i64`, `bias:i32`, `threshold:i32`, `reset_voltage:i32`, `state_bits:u8`, `decay_num:u32`, `decay_den:u32`.

`M04Response`: echo `neuron_id:u32`, `tick:u64`, `next_voltage:i32`, `spike:u8`, `status:u8` (0 OK, bit0 invalid ID, bit1 width, bit2 parameter). Invalid requests produce a status flag, **zero state/spike response**, and no memory side effect. The evaluator is stateless and does not know cache blocks, DDR, HLS core IDs, source fanout or physical event queues. It performs *one* M02 revision-1 neuron step per valid request.

**Scheduler obligations (M05 scope):** (1) Deliver all external and prior-spike currents for tick t before submitting its neuron request; preserve a mathematically exact aggregate and fail closed if it cannot be represented by signed 64-bit. (2) Use only prior-tick spikes for delay >=1. (3) Emit at most one spike/neuron/tick, deduplicate work, maintain deterministic result ordering and write next states atomically. (4) Include any nonzero prior voltage, biased neuron or any event destination in an exact-sparse worklist; don't skip autonomous, decaying or subthreshold neurons. (5) Apply backpressure so state and event buffers cannot silently lose work. (6) Integrate and verify mapping of logical ID to state-block residency separately from physical engine assignment. Neuron count 0 and neuron ID >= count are invalid. Future M05 will specify invalid tick scheduling, duplicate dispatch, spill/backpressure and physical port ready/valid; the scalar probe does not solve those cases.

**Important **bounded-domain gap:** M02 reference permits unbounded positive decay denominators and unbounded Python-integer aggregate current across arbitrarily many events, and arbitrary network size. This C++ candidate covers `state_bits=4..32`, `0<=num<=den<=UINT32_MAX`, `aggregated_current in int64 range`, `neuron_count<=UINT32_MAX`. It does **not** prove full-domain equivalence when a legal M02 input falls outside those hardware word bounds. Real M05 ingress must either (a) prove workload is within the representable subset using explicit validation **before** execution, (b) expand precision without changing the reference, or (c) request an explicit new approved numerical contract. No silent modulo/truncated conversion is permitted. The top-level C++ CLI is *host test instrumentation*, not a synthesized RTL interface.

## M04.3 candidate comparison and decision

| Candidate | Numerical fit and engineering cost | Decision |
| --- | --- | --- |
| **A. Extract v3 arithmetic** | Reuse broad ideas (widen intermediate, saturate, trace, split neural control). Directly copying `decayed_state`, `step_compartment`, 24-bit packing or threshold comparison fails M02. Refactoring them is most of a rewrite. | **Extract only patterns; don't copy neuron equation.** |
| **B. Wrap old whole-core HLS** | Needs reorder/aggregate signed event rows, override leak/threshold/current/refractory, per-core memory layout and per-timestep dispatch; copies wasteful scans/context scheduling. Wrapper alone cannot repair old equation. | **Reject as v1 default.** |
| **C. New request/response neuron step** | Simple, independent M02 mapping, does not require AXI memory layout or v3 controller. Host C++ proof provided at `hls/m04_lif_eval/`, with tests at `tests/test_m04_eval.py`. Dynamic integer division, state/stream hazards, and exact aggregate capacity may be expensive. | **Preferred prototype**, pending user acceptance and optional offline HLS synthesis. |

The C++ probe is a **candidate** for a stateless per-neuron pipeline, not a completed **streaming** AXI4-Stream core. No FIFO, multi-lane hazard scoreboard, II guarantee or DDR route is implemented. More hardware area/clock data are necessary before a freeze: dynamic integer divide, wide signed clamp, variable W, state-block read/write latency, II under repeated-neuron hazards and multiport/AXI/DDR backpressure all remain unknown. Do not assign speculative LUT/BRAM/DSP counts.
