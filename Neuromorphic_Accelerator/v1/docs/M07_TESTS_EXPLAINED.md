## 1. Scope, reference hierarchy and counters

- **M02** `evaluate_dense` and separately structured `evaluate_events` remain unchanged independent neural references.
- **M03** `build_workload`, `canonicalize_trace` and `evaluate_exact_sparse` supply fixed-seed role-isomorphic networks, independently computed eligible neurons and recurrent deliveries. Compare canonical role traces across relabelings, not raw physical IDs.
- **M06** `BlockCache`, `CanonicalImage` and `replay_with_paging` are unchanged. `BlockCache` is the preexisting exact dirty LRU. M07's `DirectFetchCache` subclasses it and supports a **strict paired read/write per logical neuron evaluation**. It uses the existing M06 version/lease/fault checks and full-block acknowledged writeback, then invalidates the just-written block. Zero reuse is permitted **between evaluations**, even on the same page; the read and write halves of ONE evaluation share the same fetched page. A second read without writing, a write to a different neuron and an incomplete flush are illegal and quarantine.
- **Block identity:** `neuron_id // neurons_per_block`; a page contains exactly `neurons_per_block * bytes_per_neuron` canonical bytes. `resident_budget_bytes` bounds resident block data, and `slots = floor(budget/page_bytes)`; metadata, queues and controller area are **not** costed.
- **Counter units:** M06 `accesses`, `hits`, `misses` refer to individual `read()` and `write()` method calls (exactly **2 per evaluated neuron**). Each M07 direct evaluation yields one miss, one hit, one page load and one full dirty page write; `direct_invalidations_not_evictions` counts explicit post-write invalidations, while M06 `evictions` counts capacity replacements only. `read_bytes`/`write_bytes` count full-page emulated canonical transfers; transactions are ceiling(page_bytes / max_model_transfer_bytes) per page transfer. An M06 LRU cache may defer dirty writeback until replacement/end flush. Because M03's original M01 analytical traffic uses **one access per neuron update** and often assumes writes on first touch, do NOT equate raw M01/M03 hit/miss counts with M06 method-level counters.
- **Fault contract:** never publish traffic as successful if independent neural traces, final canonical bytes, transfer version/ownership, or write acknowledgment disagree. Neither a partially written canonical page nor a clean flush after a fault is allowed.
- **Not modeled:** synapse DDR traffic (M06 replay keeps adjacency locally), AXI outstanding/burst/channel handshakes, B-before-AR **cycle count** and fence latency, actual FIFO backpressure, queue stalls, full service time, controller resource cost, physical DDR read/write bytes, DMA or power. Report these as `null`, not fabricated zero. M06 already has distinct original-HLS/AMD verified simulations; M07.1 does NOT rerun them or claim a new original-RTL verification.

## 5. M07.2 — four-way logical controls under direct and LRU

**Implementation:** `src/neuromorphic_accelerator_v1/m07_matched_controls.py`, `scripts/m07_four_way.py`, `tests/test_m07_matched_controls.py`. All tests are **Python host source/model only**, without a new HLS CSim, RTL elaboration, original vendor XSim, KV260/JTAG or DDR operation.

- **Same M03 fixtures:** canonical active-role graph, full per-role external-event sequence, signed weights and positive delays. Construct clustered/dispersed ID mappings with unchanged canonical role/work/traces. Every execution first runs unchanged M03 `compare_workload`, requiring M02 dense, independent M02 queued, and independently M03 safe-sparse exact parity; any mismatch refuses traffic.
- **Each policy has four controls:** `timestep/onchip`, `event/onchip`, `timestep/ddr`, `event/ddr`. Both on-chip rows are **logical M03 controls**, no transfer when available; if `N × state_bytes` exceeds `onchip_state_capacity_bytes`, on-chip controls are **UNAVAILABLE** with no invented traffic figures. Their synapses are assumed on-chip.
- **Timestep/DDR-style:** loops over every neuron at every tick, uses **M02 dense oracle** expected voltage from the previous tick, validates fetched canonical voltage and last-tick watermark, writes M02-computed next voltage/stamp via the **real M06 Python block cache**, flushes and independently checks the final image. This is an **oracle-guided canonical-state traffic replay**, not a separately implemented dense FPGA/neural kernel; source work-unit counts are N×T. Accumulate actual M06 Python cache reads/writes (two calls per evaluation), fills, dirty evictions/flush, bytes and chunk-split transaction **models**, not an AXI signal trace.
- **Event/DDR-style:** executes the actual M06 Python paged recurrent LIF through the same selected M07 direct or inherited LRU policy, with independent M02/M03 and final voltage+tick watermark checks. This uses the safe sparse evaluation subset; quiet nonzero/bias behavior and all deliveries remain exact.
- **DDR-style synapse traffic:** reuse M03 sequential precontiguous adjacency **analytical** bytes/transactions, kept separate and identified as `synapse_read_bytes_m03_estimate`. M06 replay actually keeps synapse fanout on-chip and DOES NOT make these synapse DDR reads. Summed idealized bytes are an assumption-composition, **not a connected architecture or measured DDR bus workload**.
- **Fairness/resource limits:** identical network and declared state record bytes/compute precision for all four models, paired clustered/dispersed source event counts and role-normalized neural work; but the virtualized cache is intentionally **smaller** than the full on-chip capacity and no LUT/FF/BRAM/clock/source service time equality is claimed. No on-chip comparator for oversized networks. `max_model_transfer_bytes` is capped to page bytes for canonical page transfer; M03's original maximum applies separately to adjacency transactions. Model cache tags, queues, AXI outstanding requests, B-before-AR cycle fences, channel stalls, latency, energy and physical resources remain unmeasured/`null`, **not zero**.
- **Required report:** two locality rows × two policies × four named controls; full M02/M03 canonical functional role SHA, workload SHA, declared budget, per-policy modeled state traffic/counters, M03 synaptic estimate separately, no physical timing/performance assertion. The script uses exclusive-create JSON, a new unique evidence pathname and SHA256 receipt.

## 7. M07.3 fixed-byte residency/locality ablation methods — HOST ONLY

**New source:** `src/neuromorphic_accelerator_v1/m07_ablation_sweep.py`; **CLI:** `scripts/m07_ablation.py`; **new tests:** `tests/test_m07_ablation_sweep.py`; **paper-attribution/comparability ledger:** `docs/M07_PRIOR_ART_CONFIGURATION_COMPARISON.md`.

**Default frozen experiment M07.3-GRID-A:** N=128/K=16, fanout=3 per active role, 4 signed external events/tick, T=8, seeds (17,23), two M03 role-ID placements (clustered and dispersed), exact M02 signed16 integer dynamics, state row 16 B, full-on-chip capacity 2048 B, byte-budgets (128,256,512), blocks (2,4,8) neurons. For each (seed,budget,block), **slots = budget / (block × 16 B)**, requiring exact integral slot allocation. All declared cache budgets remain strictly below the full-onchip comparison capacity and canonical image size. Up to 256 B maximum model transfer bound, capped at the page width for canonical page transfers.

**Why a byte-held sweep instead of slots-held:** comparing one 32-byte block to one 128-byte block with 'one slot' grants different absolute storage capacities. M07.3 fixes **resident bytes** for the block-size axis and derives a different slot count; separately sweeps budget in bytes at a fixed block size. This still does NOT equate tag/queue/controller area or clock speed; hardware resource matching is later work.

**Fixed-work controls:** all active-role graph edges, weights, delays, timestamped pulses and state precision are deterministic and unchanged within one seed. Role-normalized M02 voltage/spike hashes and source input SHA are invariant across all cache geometry/policy combinations. Clustered/dispersed relocation may change raw neuron-ID traces, but must preserve canonical role trace, total spikes, evaluated neuron work, synaptic traversals and external event count. Distinct seeds are independent **synthetic fixtures**, not repeated board runs or identical stochastic graphs.

**Measurement and traffic units:** M06 Python `BlockCache` and `DirectFetchCache` method-level hits/misses (2 calls per evaluated neuron), full canonical page reads/writes and `ceil(page_bytes/max_model_transfer_bytes)` model transfer chunks. M03 separate precontiguous synapse reads/transactions are **analytical** and not issued by the M06 replay. Dense timestep/state movement is driven by M02 oracle voltages, not a second implemented timestep neural RTL. Each of the 18 configurations holds 2 locality × 2 policy × 4 logical modes = **288 model rows**. `event_state_bytes_saved_by_lru` is signed **direct minus LRU bytes**; `lru_event_state_locality_penalty_bytes` is signed **dispersed minus clustered bytes**. Negative/null values are meaningful and not suppressed or called speedups. Physical bytes, service cycles and hardware area are explicitly `null`.
