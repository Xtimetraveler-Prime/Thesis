## Vendor reference guidance (informative, not execution evidence)
- AMD **SmartConnect PG247**, *Width Conversion*: connected 256→128 paths are supposed to downsize; downsizing affects burst transfer structure and requires proper AXI IDs.
- AMD **SmartConnect PG247**, *User Defined Signal Propagation*: AW/AR/B USER propagation follows defined channel semantics; incorrectly configured fields can be discarded and must be understood, not globally waived.
- AMD **SmartConnect PG247**, *Feature Comparison*: conversion internals are not public standalone IP and internal logic visibility is not guaranteed.
- AMD **Vivado UG835 2025.2**, `generate_target`: generation produces output products needed for downstream synthesis/simulation, **not** evidence of correct behavior or implemented timing.
- AMD **UG994**, *Connecting Ports with Different Widths*: lower-order-only warning can be valid in some designs but must be evaluated in context.
