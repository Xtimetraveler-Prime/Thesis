# Directed Brian2Loihi Conformance Suite

The directed suite compares the transparent Python golden model with
Brian2Loihi using twelve small deterministic experiments. Each case isolates
one behavior so the first mismatch is interpretable.

## Run

From `Neuromorphic Digital Twin` with the virtual environment active:

```bash
python -m pip install -e ".[dev,compare]"
pytest
python examples/run_directed_conformance.py --list
python examples/run_directed_conformance.py
```

Run one case:

```bash
python examples/run_directed_conformance.py --case voltage-decay
```

Stop at the first mismatch:

```bash
python examples/run_directed_conformance.py --stop-on-failure
```

Generated artifacts are written beneath `comparison_output/directed/`. That
folder is intentionally ignored by Git because the traces are regenerated by
the suite.

## Cases

1. `smoke-no-decay` — integration, threshold, spike, and reset
2. `current-decay-order` — input timing and current decay order
3. `voltage-decay` — voltage decay after an isolated impulse
4. `negative-current-rounding` — round-away-from-zero with negative state
5. `inhibitory-synapse` — purely inhibitory state evolution
6. `threshold-boundary` — exact equality versus one step above threshold
7. `refractory-one-tick` — release timing after one refractory tick
8. `refractory-three-ticks` — multi-tick refractory duration
9. `simultaneous-fan-in` — two axons summing into one neuron
10. `fan-out` — one axon driving multiple neurons
11. `mixed-excitation-inhibition` — net sum across sign-mode groups
12. `multiple-simultaneous-spikes` — simultaneous spike identities

## Result meanings

- `PASS`: both backends completed and all selected state fields matched exactly.
- `FAIL`: both backends completed, but at least one state or spike differed.
- `ERROR`: a case could not be executed because of configuration or backend
  failure.

A failure is a useful conformance result. Diagnose the earliest mismatch first;
later differences are often consequences of that initial divergence.
